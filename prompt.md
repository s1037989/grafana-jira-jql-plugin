Create a Grafana Jira data source plugin that prompts dashboard panel authors with the Jira API to query, such as Issues, list of fields to fetch, a JQL finger string, and a pageable fetch limit which will send the parameters to the admin-configured Jira instance with supplied API key for authentication and the returned JSON set is returned to Grafana in the necessary standard data frames. 
When end users view this panel the Jira query for the panel is requested of Jira l and the results returned in real time. Results should be cached in order to limit impact to the production server and lower RTT.
